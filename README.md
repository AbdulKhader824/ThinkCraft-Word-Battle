# ThinkCraft Word Battle

Think fast. Find unique words.

A multiplayer word game built with Flutter. The first version simulates other
players locally, and online play is planned for a later phase.

## Run it

```powershell
flutter pub get
flutter run -d chrome
```

## Check it

```powershell
flutter analyze
flutter test
```

Project rules and design decisions are in `CLAUDE.md`, and the original briefs
are in `docs/spec.md`.
